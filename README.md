# VIVIDLOPE

[Setup Guide](setup_en.md)

## What does randomization do to this game?

The following items are unlockable:
- Access to each level, including Level X and Finale (Level X and Finale are toggleable)
- The ability to use each power-up, as well as Ms. Noir's attacks
- Some extra level elements like Paint Rollers and Snowmen
- Attires
- Access to the shop (progressive)
- Inventory items (filler)

Location checks include:
- Clearing each stage, and optionally earning a certain rank
- Clearing each level
- Buying items from the shop

You can also shuffle the level that each stage appears in, and there are various configurable trap items that spawn enemies into the current stage.

## What is the goal for this game?

Clear a configurable amount of levels, then complete either Finale or Level X.

## What does another world's item look like in VIVIDLOPE?
Only items in the shop have a visual appearance, and appear as a stylised version.

## When the player receives an item, what happens?
You will get a popup message when you receive/send an item. Note that some popups may not display due to loading screens or other factors.
